# 模块总结：拟人化防封引擎模块 (`core/humanizer`)

## 1. 模块职责与设计目标
`core/humanizer` 模块是整个自动化系统在安全层面的核心屏障。Supercell 的服务端风控不仅检测客户端内存修改，还会统计玩家交互行为的统计学特征（如点击坐标方差为 0、点击时间间隔呈固定周期、滑动轨迹斜率恒定、24 小时无休在线）。本模块从**空间、时间、轨迹、作息**四个维度对所有自动化指令进行仿生学包装。

## 2. 包含的文件清单
- [jitter.py](jitter.py)：实现 `HumanJitter` 类，提供二维高斯坐标偏移、随机手指按压时长、对数正态分布反应延迟以及三阶贝塞尔曲线滑动轨迹。
- [scheduler.py](scheduler.py)：实现 `SessionScheduler` 类，提供动态会话时长限制与夜间仿生睡眠窗口判断。
- [__init__.py](__init__.py)：导出 `HumanJitter` 与 `SessionScheduler`。

## 3. 核心算法与技术亮点
1. **二维截断高斯分布点击偏移 (`jitter_point`)**：
   - 围绕目标中心 $(x, y)$ 按正态分布 $\mathcal{N}(0, \sigma^2)$ 生成偏移量，并截断在 `[-max_offset_px, +max_offset_px]` 范围内，使点击热力图与真实人类拇指点击分布完全吻合。
2. **对数正态分布反应延迟 (`sleep_human_delay`)**：
   - 摒弃易被统计学识破的 `random.uniform` 均匀分布，采用认知心理学中描述人类视觉反应时间的**对数正态分布（Log-Normal Distribution）**，自然模拟出“大多数操作流畅、偶尔出现短暂思考停顿”的长尾分布。
3. **带 Ease-In-Out 速度包络的三阶贝塞尔曲线 (`generate_bezier_curve`)**：
   - 在起点与终点之间随机生成两个偏离直线的控制点 $P_1, P_2$，并利用余弦变换 $t = \frac{1}{2}(1 - \cos(\pi \cdot t_{\text{linear}}))$ 实现人类手指滑动特有的“起步加速 → 中段高速 → 终点减速停靠”非线性轨迹。
4. **浮动会话与夜间作息调度 (`SessionScheduler`)**：
   - 每次会话上限在设定值（如 75 分钟）的 `±20%` 区间内随机浮动，达到上限后自动挂起休息，并在夜间睡眠时间窗（如 `01:30-07:30`）自动进入深度休眠。
