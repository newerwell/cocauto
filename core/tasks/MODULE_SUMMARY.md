# 模块总结：四大核心业务状态机模块 (`core/tasks`)

## 1. 模块职责与设计目标
`core/tasks` 模块将底层的设备控制层 (`core/device`) 与视觉感知层 (`core/vision`) 编排为《部落冲突》的四大高层自动化业务闭环：**村庄日常收菜与智能捐兵**、**自动搜鱼与资源过滤**、**基于动态红线的智能战斗与英雄开大**、以及**基于“工人建议列表”的自动刷墙与建筑升级**。

## 2. 包含的文件清单
- [village_routine.py](village_routine.py)：实现 `VillageRoutineTask`，负责回村视角归一化、采集器资源气泡点击收集、部落聊天面板关键词白名单/黑名单智能捐兵、以及一键快速训练补兵与请求援军。
- [loot_searcher.py](loot_searcher.py)：实现 `LootSearcherTask`，负责联机匹配云层等待、左上角金/水/黑油 OCR 读取、死鱼采集器满度过滤及循环点击“下一个”。
- [combat_ai.py](combat_ai.py)：实现 `CombatAiTask`，支持开局真人感四向侦察、先左右两翼清边后中路主力+攻城车+四王一齐推进、右下角摧毁率 10~15 秒停滞自动放弃、以及战斗结束结算页自动回营。
- [auto_upgrader.py](auto_upgrader.py)：实现 `AutoUpgraderTask`，通过点击顶部“建筑工人头像 → 建议升级列表”实现零误差自动刷墙与推荐建筑升级，并完美支持“预留 1 名空闲工人专门刷墙”策略。
- [night_world.py](night_world.py) 负责夜世界资源、渡船、匹配和战斗。二阶段由新战场与新兵栏确认，每阶段独立登记槽位。
- [deployment.py](deployment.py) 为两个世界共用下兵流程，校验镜头和选中态，记录触点、确认余量并生成阶段摘要。
- [__init__.py](__init__.py)：统一导出五大任务状态机。

## 3. 核心业务亮点
1. **每种物资严格仅点 1 次的双态自动收菜 (`collect_resource_bubbles` & `run_collect_only`)**：
   - 利用《部落冲突》“点击 1 个同类采集器气泡即自动收取全村同类资源”的机制，在主村庄安全区 `VILLAGE_MAP_ROI = (80, 560, 150, 1050)` 内对 **金币 (`Gold`)**、**圣水 (`Elixir`)**、**暗黑重油 (`Dark Elixir`)** 分别独立匹配“正常白底气泡”与“满仓红底气泡”双模板，每类物资仅选取置信度最高的那 1 个气泡点击 1 次（单轮最多 3 次点击），彻底杜绝重复点击打开底部建筑详情栏。
   - 提供 `run_collect_only()` 独立收菜测试入口，与部落捐兵、请求援军和快速补兵彻底解耦，支持分模块逐项调试。
2. **基于语义黑/白名单的部落捐兵 (`should_donate_for_message`)**：
   - 自动截取部落聊天 `[增援]` 按钮上方的请求文本区域，一旦识别到“不”、“勿”、“只要超级”、“攻城”等黑名单词汇立即跳过，避免捐错兵被踢出部落。
3. **主世界与夜世界下兵**
   - 移镜后用两张新帧确认当前视角，再按两翼、中路和英雄扇形的顺序搜索可部署地块。法术使用核心目标网格。
   - 每个槽先试投 1 个，按实际扣减决定下一批数量，单批最多 4 个。镜头切换会清除该侧已验证的落点。
   - 每阶段复扫兵栏，返回剩余槽位、最后一次可信读数和失败原因。窗口中的单步和循环入口共用摘要。
   - 通过桌面或 CLI 调度实际设备时，触点和前后余量写入 `logs/deployment/<world>-<phase>-<id>/attempts.jsonl`。无进展、余量未知或落点失效时，同目录保存前后帧和触点图。
4. **工人建议列表刷墙与“留 1 工刷墙”算法 (`plan_upgrade_actions`)**：
   - 彻底告别在 2.5D 地图上盲目找墙。点击顶部工人图标（`545, 32`）打开下拉菜单后选中“城墙”，由游戏引擎自己移动镜头并选中未满级城墙；且仅当 `free_builders > reserve_builders_for_wall` 时才允许升级耗时数天的普通建筑，确保永远留有 1 名空闲工人随时消耗打鱼溢出的金币和圣水。
5. **排位赛“进攻已完成！(12/12)”双重检测 (`LootSearcherTask.check_ranked_battle_status`) 与主世界点击渡船前往夜世界 (`VillageRoutineTask.travel_to_builder_base`)**：
   - **排位赛完成状态检测**：在 `联机模式` 面板自动结合 `RapidOCR` 场次比例读取（如 `12/12` 或 `"完成"`）与右侧排位战橙色进攻按钮消失对比（`reg_orange >= 0.35` 且 `rank_orange < 0.08, mean_V < 105`），一旦检测到排位赛已完成立即关闭面板返回主世界，不再盲目点击。
   - **主世界左下海岸渡船前往夜世界**：支持全景视野检查、左下海岸线对齐拉镜 `(280, 540)->(560, 340)`、`boat_to_night.png` / `boat_bubble.png` 双模板匹配点击 `(263, 546)` 以及夜世界夜间蓝绿光照视觉到达确认 (`is_in_builder_base`)。
