# 模块总结：自动化测试与合成视觉验证模块 (`tests`)

## 1. 模块职责与设计目标
`tests` 模块提供无需连接真实手机或启动安卓模拟器即可运行的**无头（Headless）全链路单元测试与合成视觉验证套件**。通过 `MockAndroidDevice` 动态绘制包含敌方红色禁区线、满液位圣水收集器紫品红液柱以及受损英雄生命条的 `1280×720` 合成战场画面，对所有 6 大模块进行端到端回归测试。

## 2. 包含的文件清单
- [test_all_modules.py](test_all_modules.py)：包含 6 个核心测试用例，覆盖配置加载、二维高斯偏移与三阶贝塞尔轨迹、双指捏合多点触控协议、动态红线四边检测与死鱼满采集器识别、“留 1 工刷墙”决策逻辑以及总控状态机完整单轮闭环。

## 3. 运行测试命令
```powershell
python -m unittest discover -s tests -v
```
